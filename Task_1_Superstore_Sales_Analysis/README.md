Task 1 - Superstore Sales Analysis
Project Objective
Analyze customer purchase volume, monthly seasonality, category-wise revenue, and discount sensitivity using Python and data visualization techniques.

Dataset
Superstore Sales Dataset

Python
Pandas
Matplotlib
Seaborn
Jupyter Notebook
Analysis Performed
Data Cleaning
Missing Value Handling
Order Date Transformation
Monthly Seasonality Analysis
Category-wise Revenue Analysis
Region-wise Performance Analysis
Customer Segment Analysis
Discount vs Profit Analysis
Correlation Analysis
Key Findings
Technology generated the highest revenue ($834,554).
West region delivered the highest sales ($725,458) and profit ($108,418).
Consumer segment generated the largest revenue contribution ($1.16M).
Sales consistently increased during the final quarter of each year, with November 2018 recording the highest monthly sales.
A negative correlation (-0.219) was observed between discount and profit, indicating that larger discounts tend to reduce profitability.
